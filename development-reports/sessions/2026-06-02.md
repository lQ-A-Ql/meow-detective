- `get_media_url` 对大媒体返回 `MediaPreviewModeDto::Protocol`、opaque handle 和 protocol URL；小媒体继续返回 bounded inline data URL；`read_media_range` command 保留为 fallback。CSP 只在 `media-src` 允许 `evidence-media:`，不新增宽泛 asset scope。
- 新增 `artifacts-windows::registry::lookup` 定向 Registry reader，bounded 读取最多 64MB，解析 `regf` base block、NK/VK、`lf/lh/li/ri` 子键列表和 `REG_SZ` / `REG_EXPAND_SZ` / `REG_DWORD` / `REG_QWORD` / `REG_MULTI_SZ`；Analysis 从 SYSTEM/SOFTWARE 提取 hostname、timezone、ProductName、build、install date、owner/org/product id，并输出字段级 provenance。
- 新增 `artifacts-windows::evtx` adapter，使用 `evtx` crate bounded 解析 System.evtx 中的 6005、6006、6008、1074 候选事件；Analysis boot records 带 event id、record id、note 和 provenance，并明确这些是 EventLog/User32 candidates，不是绝对开关机事实。
- DataAnalysis、mock data、frontend models 和 reports 同步新增 field provenance、EVTX event fields 和 parser/source 展示；HTML escaping 与 CSV formula sanitization 回归测试保留。
- `deny.toml` 新增 `RUSTSEC-2021-0153` 临时例外，跟踪 `evtx -> encoding` unmaintained transitive advisory，owner/reason/expiry 均已记录。
- 更新 `docs/remediation-plan-v2.1.md`、`docs/architecture-model.md`、`docs/algorithm-complexity-analysis.md`，修正旧的 Partial/stub 状态。
