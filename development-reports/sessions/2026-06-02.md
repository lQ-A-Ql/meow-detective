- 复核剩余 backlog 后选择本地可验证的 Phase 6.1 子项，避开需要外部样本或人工 smoke 的 EVTX/tiny E01/media protocol 项。
- 在 `evidence-core::filesystem` 新增公共 helper：root node、path join、常见 path/file not-found 和 directory/not-directory error。
- `fs-fat`、`fs-ntfs`、`fs-exfat` 改为复用公共 helper，删除重复 root node 构造和本地 path join/error 构造。FAT/NTFS 继续输出 slash-separated path；exFAT 继续输出 backslash-separated path。
- 更新 `docs/remediation-plan-v2.1.md` 和 `docs/开发记录.md`，把 Phase 6.1 标为 Partial，明确本轮不是完整 FS 枚举流程 refactor。

### 验证结果

- `cargo fmt --all -- --check`: 通过。
- `cargo test -p evidence-core filesystem`: 通过。
- `cargo test -p fs-fat`: 通过。
- `cargo test -p fs-exfat`: 通过。
- `cargo test -p fs-ntfs`: 通过。
- `cargo test -p app-services file_service`: 通过。
- `cargo test -p app-services --test file_service_real_test`: 通过。
- `cargo clippy --workspace --all-targets -- -D warnings`: 通过。

### 剩余风险

- FAT/NTFS/exFAT 深层枚举流程和 FS 特定错误转换仍可继续去重，但需要更大行为回归面。
- 本轮保持 public API、root semantics、排序和 path separator convention 不变。
