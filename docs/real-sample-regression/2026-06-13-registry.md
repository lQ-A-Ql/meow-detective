### 提取说明

- NTUSER.DAT 按用户 profile 层级发现：遍历 `Users/` 下子目录，对每个包含 `NTUSER.DAT` 的用户执行提取
- 字段提取采用定向 key path 读取，不走完整 hive 枚举
- shell_folders 解析为 `{GUID} → 路径` 映射，与 Known Folder GUID 表关联以生成友好名称
- recent_files 提取 RecentDocs 下按扩展名分组的 MRU 列表，含文件路径与最后写入时间
- run_mru 提取 `RunMRU` 下的启动命令历史，按 MRU 顺序排列
- open_save_mru 提取 `ComDlg32\OpenSavePidlMRU` 下按扩展名分组的文件历史，从 PIDL 二进制中恢复文件名
- last_visited_mru 提取 `ComDlg32\LastVisitedPidlMRU` 下最近访问目录历史，从 PIDL 二进制中恢复路径
- typed_paths 提取 Explorer 地址栏手动输入路径历史

### 提取说明

- SAM hive 以 SYSTEM hive 的同名 key 解密，或通过已知 syskey 派生解密
- 用户信息解析自 C:\ 格式的注册表 value 结构 (F 结构体)，含 login_count、最后登录时间、账户控制标志
- 组成员关系从 `SAM\Domains\Builtin\Aliases\<RID>` 的成员列表解析
- 本地组映射：`Administrators` (RID 544)、`Users` (RID 545)、`Guests` (RID 546) 等

## Transaction Log (txlog) 集成状态

### 当前能力

| 能力 | 状态 | 说明 |
|------|------|------|
| txlog 文件发现 | ✅ 已实现 | 自动发现 .LOG1、.LOG2 文件 |
| txlog 脏页标记读取 | ✅ 已实现 | 解析 dirty page vector，识别哪些 hive 页有未提交变更 |
| txlog → hive 合并 | ✅ 已实现 | txlog dirty page vector 解析后，脏页内容合并回 base hive 解析结果 |
| txlog-only 键值恢复 | ✅ 已实现 | txlog 中已提交但 base hive 中不可见的键值可提取 |

### 影响评估

- **影响范围**: txlog dirty page 合并已实现，非正常关机场景下的未刷盘事务可恢复
- **覆盖率**: .LOG1 和 .LOG2 文件均解析，dirty page bitmap 驱动合并，以 txlog 版本覆盖 base hive 过期页
- **验证**: liuyang_pc.E01 为正常关机镜像，txlog 脏页数量有限；合并后 SYSTEM/SOFTWARE/SAM/NTUSER 提取结果与 base hive 一致

### 实现路径

1. 解析 .LOG1/.LOG2 的 header → dirty page bitmap
2. 为每个 dirty page 在 txlog 中定位对应 sector
3. 当 hive 页在 txlog 中有更新版本时，以 txlog 版本覆盖 base hive 页
4. 合并后的 hive 视图送入已有的定向 key path 提取链路（已实现）
