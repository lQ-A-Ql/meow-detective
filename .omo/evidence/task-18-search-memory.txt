## Notes
- Added highlighter safeguards only: scanned content is capped at 256 KiB, matching the existing import text-index per-file budget; returned snippets are capped at five per hit; each snippet text is capped at 512 bytes.
- Tantivy indexing/search semantics were preserved; `SearchIndex::index_documents` and app-services search behavior were not changed.
- Added large synthetic content tests for bounded snippet count, dense-match bounded snippet text, and direct scan-cap behavior; added many-result coverage preserving hit limit with total count.
- Existing zero-result coverage was already present in both `crates/search/tests/indexer_test.rs` and `crates/app-services/tests/search_service_test.rs`.
- LSP diagnostics were attempted for changed Rust files but failed because `rust-analyzer.exe` is missing from the stable Windows toolchain; cargo gates above were used as fallback.
