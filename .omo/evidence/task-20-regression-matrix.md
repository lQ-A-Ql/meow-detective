## Unresolved and Manual Caveats

- LSP diagnostics were not available in this environment. The recorded fallback path was command-based verification because `rust-analyzer.exe` was unavailable from the stable Windows toolchain and `typescript-language-server` was not installed. See `.omo/notepads/engineering-audit-remediation/issues.md` and `.omo/evidence/task-19-quality-gates.txt`.
- `cargo test --workspace` included ignored paths that still depend on external fixtures. That includes E01 and real fixture scenarios guarded by `FORENSICS_E01_FIXTURE` or local sample availability. The matrix does not treat those ignored paths as automated coverage.
- Frontend large-data verification is based on targeted Vitest and jsdom assertions for bounded rendering. It is useful regression evidence, but it is not the same as a full desktop runtime profile with production-sized evidence sets.
- MCP compatibility intentionally preserves a mixed boundary. Top-level Tauri arguments are camelCase, nested MCP protocol DTOs stay snake_case. That behavior is tested and documented rather than hidden.
- Provenance for legacy rows is surfaced through explicit unknown or missing states. The evidence does not claim that old records were backfilled with historical parser, extractor, or hash detail.
