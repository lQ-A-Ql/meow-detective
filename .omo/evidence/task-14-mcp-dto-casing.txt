Task 14 MCP DTO Casing and Error Compatibility Evidence
======================================================

Chosen casing strategy:
- Tauri top-level command args remain camelCase from frontend: serverId, promptName, config, server, request.
- Nested MCP protocol DTO/request fields remain snake_case at the Rust/Tauri protocol boundary: transport_type, auto_connect, server_id, tool_name, mime_type, input_schema.
- frontend/src/lib/api/mcp.ts explicitly maps snake_case protocol DTOs to camelCase safe API models before the Zustand store sees them.
- Malformed/unknown config/status/resource/tool/prompt/tool-call responses are normalized to safe fallbacks by the API layer so the store/UI does not crash.
